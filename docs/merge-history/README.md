# Tài liệu từ nhánh GitHub được giữ lại khi xử lý merge

Các file `incoming-*.md` là nguyên văn tài liệu ở nhánh được merge vào, được lưu riêng để không mất nội dung của hai phía. Những báo cáo này ghi lại trạng thái tại thời điểm nhánh đó được phát triển; không phải kết quả kiểm tra lại trong lượt sửa conflict hiện tại.

Tài liệu tích hợp gốc của nhánh local tiếp tục nằm ở `docs/integration-*.md`. Trạng thái sau sửa conflict, giới hạn kiểm chứng và cách chọn chế độ frontend nằm trong [MERGE_RESOLUTION_REPORT.md](../MERGE_RESOLUTION_REPORT.md).
