# Ma trận tích hợp cuối — 05/11/2026

## Phạm vi và cách đếm

- **80/80** cặp method/path đã đối chiếu router và public handler; không tính API ngoài danh sách.
- **79 thao tác có lời gọi trực tiếp trong luồng UI REST**, **1 thao tác dùng chức năng gián tiếp**: GET bảng giá công khai được đọc qua trường `rates` của GET chi tiết phòng, tránh tải trùng. Đây là ánh xạ source, không phải số API đã nghiệm thu runtime.
- **44 thao tác từng ghi “Chưa có” được nối trực tiếp bằng REST**. Các chức năng từng dùng commands/workspace nay dùng REST tương ứng; không gọi cả hai mutation. **36 thao tác còn lại** được giữ/điều chỉnh contract; GET amenities nay phục vụ tạo phòng.
- **79/80** thao tác xuất hiện trong bài kiểm thử trình duyệt bằng fixture của lượt này. Các test transport/unit bổ sung kiểm tra riêng; không cộng nhầm vào số PHP HTTP.
- **0/80 VERIFIED_HTTP**, **0/80 VERIFIED_DATABASE_PERSISTENCE**. Runtime PHP tại cổng 8000 không truy cập được; 80 thao tác chưa thể nghiệm thu PHP/DB.

Tên file consumer dưới đây tính từ `client/src`; thông tin handler/dòng lấy từ `server/public/index.php`. Các dòng runtime-unverified không đồng nghĩa endpoint thiếu hay đã hỏng.

## Contract theo trang

| Trang / component | Quyền | Request chính | Response thực dùng | Refresh / trạng thái |
|---|---|---|---|---|
| /login, /register · ApiAuth | Guest | email,password; register thêm full_name,phone | token,user | SessionStorage JWT hiện có; điều hướng theo role; không đưa Host/Admin vào trang Customer mặc định |

## API chung ngoài 80 thao tác

GET /api/workspace, POST /api/commands, GET /api/reports đã được đọc contract; adapter và connected mode cũ được giữ. Luồng REST hiện dùng endpoint riêng để tránh tải dữ liệu rộng và tránh mutation trùng. Không tạo consumer giả hoặc gọi /api/reports chỉ để tăng số endpoint. POST /api/host-applications/current không tồn tại; frontend dùng GET /api/host-applications/current (API phụ ngoài danh sách 80).
